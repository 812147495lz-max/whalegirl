# WhaleGirl · Native glass UI

Reference: [ui-design](https://github.com/812147495lz-max/ui-design/tree/db8d1113e3d22936f5f996dcdbb365deff0e9f72/extensions/universal-gui), especially FOUNDATIONS, DATA_AND_OPERATIONS and the bubble-glass example. This is an AppKit adaptation of that design guidance, not a new web frontend or an installation of its scripts.

Every custom surface uses the same semantic palette, native Chinese/Latin system fonts, tabular live values, blue interaction accent, 8/16-point layout rhythm and matching rounded cards. Compact panel headings14pt, utility headings20pt, controls12pt, readable metadata11pt; chart axes11pt matching the shared numeric baseline within compact plots. Container corners20pt and utility card corners14pt are deliberate native-density adaptations. Main settings, AI, network, dashboard, information card and speech bubbles share tokens. Native macOS menus/dialogs retain native semantics.

Light: background #E8F0FF, surface #F5F9FF, primary #162943, secondary #436077, accent #3578D4, border #B5CAE5. Dark: #0B1427, #1E2B43, #F0F7FF, #BDD2E8, #9CDCFB, #526987. Secondary data series use teal; warning colors remain semantic. Glass uses readable backing and a solid fallback for reduced transparency/high contrast. Live figures and chart paths are never distorted by material effects.

Information card: compact single-column metric rows,12pt outer horizontal padding,4pt row gaps,20pt minimum row height and shared11pt medium monospaced readings. CPU/GPU/memory/storage use the same rows as network/battery/temperature; capacity shares the percent line. Optional36pt sparkline plots sit below their value rows, network addresses below traffic, AI quota last. Provider name and remaining values share one row. Repeated timestamps, legends and activity notes use relevant tooltips. All metric and address values share a hard-constrained right edge. Numeric fields have explicit leading/trailing anchors, with no empty trailing action column; do not rely on stack content hugging to expand a right-aligned field. Speed sits immediately after the network label. Address refresh sits immediately after the public-IP name; IPv4 and full-row IPv6 share the same trailing edge with no reserved empty action column. LAN and public addresses each get their own selectable row, with IPv4 before IPv6; IPv6 uses the full card row without reserved name/action columns and scales its monospaced font to retain every digit on one line; an IPv6-only group places its title/action in a separate preceding row. Main scrolling uses overlay indicators only for measured whole-page overflow; quota has natural height without a nested height cap. Estimated panel height includes full-width address rows and any IPv6-only group header. Detail controls are progressively disclosed; explanatory text stays in help or relevant error states.

Charts: independently selectable CPU, GPU, memory, network, battery, temperature. One shared1s sampling clock, at most5min in-memory history, explicit percent / temperature / throughput units, one time-window label only on the first enabled chart, two series for network and temperature, no data gaps bridged and no invented zeros. Startup has no historical samples; the visible time window expands from30s to5min as real samples arrive. Unsupported hardware remains unavailable. Existing value visibility preferences remain independent; enabling a plot also reveals its metric. Plot choices persist locally.

Addresses: active non-loopback LAN interfaces are read locally. Public IPv4 and optional IPv6 egress use bounded concurrent HTTPS requests to api.ipify.org and api6.ipify.org with a5min cache, only when network addresses are shown or manually refreshed. It may be a proxy/VPN egress. No address history is written.

Quota: optional native vector remaining-quota rings, enabled by default and switchable only in AI management; keep the main section header to its title and management action. Two equal software columns per row, each ring view64×62pt. Inner blue ring and upper number show hourly REMAINING; outer teal ring and lower number show weekly REMAINING. Ring strokes4.5pt; no needles, ticks, redundant percentage summary or legend. Real reset countdowns sit beneath, with missing timestamps omitted. DSH uses one CNY remaining ring with a locally saved editable maximum (default50 yuan), no implied currency conversion. Clamp only the arc, never the numeric balance; preserve long balance text below the ring when it cannot fit inside at the shared font size. Other real quota buckets remain in text. Missing/stale readings use neutral rings and dashes, no invented zero. All information-card numeric data, ring values, reset durations and chart axes share the LAN IPv6 baseline:11pt medium monospaced; only full-width IPv6 may scale to preserve every character. Existing blue/teal/warning colors and heading/control hierarchy remain. No independent animation/timer. Preserve natural section height and whole-panel overflow. Retain real reading timestamps and missing/stale semantics. Show reset countdowns only when the provider supplies a real reset timestamp, with days/hours and smaller units near reset; omit missing timestamps entirely. Refresh countdown presentation on the existing clock, without new network calls. Use DSH consistently as the provider label; its working companion shows the remaining time to the next actual peak/off-peak change. A completed root reply/session gets the available remaining quota, marking older readings as the last reading; unsupported/missing data is explicit. Codex recovery uses observed fresh quota increases/reset transitions and a persisted de-duplication state, never the reset timer alone. Children remain quiet. No new system notifications.

Validation for this update is intentionally limited by the user to compilation, opening and basic display/control checks. No broad test-suite, paid model task, multi-display, Intel-hardware or load acceptance is implied.

Text-only quota mode: provider name stays in the left60pt column; the wrapping reading field has explicit leading/trailing and top/bottom anchors, matching the outer information content right edge. No extra quota-list trailing inset. All paragraphs (percent/balance/reset/price transition) align right inside that same field; measure its width and vertical insets for natural height.

Quota layout has no internal NSScrollView or fixed-height anchor. Header plus rows derive the section height from content constraints; the whole information card owns overflow. The static height estimate is only for panel sizing, not a clipping constraint.
