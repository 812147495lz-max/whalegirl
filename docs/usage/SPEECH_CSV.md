# 编辑气泡文案

运行时文件：`~/Library/Application Support/WhaleGirl/UserData/气泡文案.csv`。建议从菜单“编辑气泡文案 CSV”直接打开。
菜单栏中键或 Option+右键打开控制菜单，选择“编辑气泡文案 CSV”，会用文本编辑打开原文件。
电脑信息展开时，左键同样可以进入这个控制菜单。

第一行为 `气泡文案`，之后每行一句，例如：

```csv
气泡文案
今天也要记得喝水呀。
主人忙吧，我陪着你。
"Hello, 主人！"
"本鲸说：""该休息啦。"""
```

直接保存原 `.csv`，下一次新气泡就会从最新内容随机抽取，不用重启。
当前正在显示的气泡不变。探头和桌面鲸鱼娘共用文案；有其他候选时避免连续重复。
删除示例行即可只播放自己的文案。空行和重复行会被忽略，表头也可省略。
普通文本编辑即可；如果使用 Numbers/Excel，必须保存或导出回同一个 CSV 路径，
保存为 `.numbers` / `.xlsx` 不会更新该文件。菜单默认用文本编辑，以免误存格式。

文件支持 UTF-8（含 BOM）和带 BOM 的 UTF-16。英文逗号、英文双引号或换行
要使用标准 CSV 引用（如上例），中文逗号无需处理；只使用一列。
读取最多 1 MiB，不执行任何内容。保存到一半、文件为空/格式错误、暂时不可读或被删除时，
保留内存中的上一次有效文案；首次启动无有效内容则使用内置文案。
启动或点击编辑入口时，只创建不存在的文件，不覆盖用户已有文件。
仓库中的 `Examples/气泡文案.csv` 仅是模板，不是运行中的文案文件。

新版不再自动读取文稿目录，避免启动触发文稿访问授权。旧版自定义文案可手动复制到上述位置；先备份目标文件。此次本机升级已复制并校验旧文案，旧文件保留，之后编辑新版菜单打开的文件。
