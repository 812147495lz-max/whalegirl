# Token 用量与费用报表（本地 v1.6.2）

菜单栏图标中键／Option+右键 → **Token 用量与费用报表…**。

- 支持本机 DSH 与 Codex 的已落盘用量元数据。新的模型调用用量到达后，桌宠自动弹文字气泡，按顺序显示输入、输出、缓存命中、缓存未命中和可用费用。仅对应会话的主任务桌宠和手动拖出的桌宠可以播报；子代理不播报，没有可用桌宠时安静记录到报表，不触发菜单栏探头。
- 余额气泡改为仅在鼠标停到角色身体上时上浮出现，移开隐藏。自动用量气泡不依赖悬停，约8秒；云朵形思考框以三颗逐渐变小的圆泡连接到角色头顶附近，按裁切后的角色边界定位，完整露出人物，已去掉粉色爱心。保留全屏避让。
- 报表可筛选DSH/Codex、今天、最近7天／30天，查看每条记录及汇总；**导出 CSV…**导出当前筛选结果，包含UTF-8 BOM，Excel等可读取。缺失数值留空，费用币种与口径单列。
- “自动播报”可单独关闭，关闭后仍继续记入报表；静音模式同样抑制气泡。重启与历史补读只更新报表，不补弹历史消息。

## 数字口径

输入合计包含缓存命中和缓存写入；输出合计包含推理。缓存／推理等分项不再重复加到总数。两套工具原始字段口径不同，由适配器统一；字段缺失时显示“—”，不当成0。

这里的记录来自工具本地元数据，不等于官方账单。**Codex当前本地用量没有实际金额字段，因此费用显示“未提供”**；不会把订阅额度、Token数量或余额变化冒充逐次扣款。DSH 的 DeepSeek 调用改为按[官方人民币价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)计算，气泡显示 **官方价估算 ¥…**。按记录中的实际模型、发生时间（北京时间）、缓存命中、非缓存输入（含缓存写入）和输出（已含推理）计算，避免重复计费。历史记录可补齐金额，不重弹历史气泡。未知模型或分项不齐时不猜金额；官方表不覆盖的记录仍可保留插件 USD 估算。不同币种分别合计，实报与估算分别合计。

DSH以会话＋turn/step识别请求，压缩摘要按日志序号识别；同一步内未提供独立身份的多个成功重试无法拆开。Codex优先使用响应身份并合并镜像通知。此能力不拦截模型流，也不逐个字符推测Token或费用。

## 本地存储与限制

- 只投影用量、时间、公开模型名称、哈希会话身份与费用字段，不保存提示词、回复、工具内容或凭据，不增加模型调用或网络查询。
- 应用数据目录的UserData下保存`usage-collector-v1.json`、`usage-last-report-v1.json`、`usage-notified-v1.json`；最多保留10000条。CSV由用户自行选择位置。
- 每3秒在后台分批读取，初始化较大历史时显示“部分读取”，继续补读。文件数量／压缩帧／读取体积均有上限，所以报表不是所有历史会话的完整账本。
- DSH压缩文件读取依赖本机可用libzstd；当前开发机已用系统Python3验证。其他机器缺少解码库会显示不可用，不自动安装依赖。未来变更为仅SQLite存储的DSH版本需要新适配。
- 原来的余额观察账本、CSV台词、额度显示偏好和Agent事件桥不变；无需重新安装Hook或重启DSH。

## DeepSeek 官方价快照（2026-10-23 核对）

单位：人民币元／百万 Token。Flash 支持官方别名 `deepseek-flash`、`deepseek-v4-flash`、`deepseek-v4-flash-vision-exp`；Pro 为 `deepseek-v4-pro`。

|模型|空闲缓存命中|空闲未命中|空闲输出|高峰缓存命中|高峰未命中|高峰输出|
|---|---:|---:|---:|---:|---:|---:|
|Flash|0.02|1|4|0.04|2|8|
|Pro|0.15|4.5|13.5|0.30|9|27|

公式：`(命中 × 命中单价 + (输入总数 − 命中) × 未命中单价 + 输出总数 × 输出单价) ÷ 1,000,000`。高峰为北京时间周一至周五 09:00–12:00、14:00–18:00，中国法定节假日除外，其余为空闲。使用包内已核对的2026节假日表；保守价格覆盖为2026-09-19至2026-12-31，其他时期不套用这张表。价格快照随软件更新；不额外发起计费 API 或汇率查询。

报表费用提示、明细和 CSV 的 `cost_basis` 保存计算依据，汇总计入 CNY 估算。官方价估算表示这部分模型 Token 的按量价格，不代表套餐实际扣款；Search/Fetch 等非 Token 项目不包含在其中。Codex 中只有明确识别为以上 DeepSeek 模型且分项完整的记录才使用此表，其他模型不套用 DeepSeek 价格。
