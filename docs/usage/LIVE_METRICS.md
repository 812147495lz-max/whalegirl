# 实时指标与额度提醒

信息卡右上角的选择按钮打开电脑信息设置。CPU、GPU、内存、网络、电池、温度各有折线图开关；默认显示 CPU 与网络图。开启图表会同时显示对应指标，关闭图表保留当前数值。选择会保存在本机。

信息卡仅在整体内容实际超过可见页面时显示浮动滚动条，额度区域不再单独限制高度。内容未超过一页时不占用右侧空间。

紧凑信息卡中，各项指标按行显示；容量与占用率合并一行，额度采用软件名与剩余值同一行，详细更新时间、图例和状态说明可悬停查看。

图表每秒采样，最多显示最近5分钟；刚启动时从30秒窗口逐渐扩展。百分比以0–100%为范围，网络图显示下载和上传，温度图显示 CPU 和 GPU。各图显示单位，时间范围只显示在第一个启用的折线图右上方；缺失读数留空，不补零。历史仅在内存中，重启后重新累积。部分硬件不支持 GPU/温度读取时显示不可用。

网络、电池、温度的数值保持对齐。“测速”位于“网络”文字旁，点击打开信息卡旁的快捷选择，详细逐跳信息与参数在“详情与设置”。IP 开关位于电脑信息设置；显示活动物理网络接口的内网 IPv4/IPv6，每条地址单独显示，IPv4 优先，可选中复制；IPv6 独占整行并按长度适配字号，全文显示，不换行或省略。出网 IP 分别通过 HTTPS 查询 IPv4 与可用的 IPv6，也各自完整显示；仅展示实际取得的地址，IPv6 不可用时不添加空地址。最多缓存5分钟，可点击刷新；代理或 VPN 可能改变这个出口。查询失败显示不可用，不保存 IP 历史。

点击 AI 余量右侧“管理”，用“显示额度仪表”控制仪表开关；主卡不再单列开关。开启时每行并排两个软件，64×62pt 小型双环的内蓝环与上方数字表示小时剩余，外青环与下方数字表示周剩余；已知的重置倒计时排在环下，没有时间就省略。缺失或过期数据不填成0；未知读数显示短横线。关闭后回到文字列表。DSH 为人民币剩余额度单环，默认满量程50元，在 AI 管理的“DSH 满量程”中调整，回车或离开输入框保存。读数超过量程时圆环封顶，数字不裁剪；没有人民币余额时不猜测换算。开关和满量程在重启后保留。

AI 额度每个周期在有真实重置时间时显示“几天几小时后重置”等倒计时，约30秒更新显示；没有重置时间就省略，不添加“时间未知”。DSH 不显示不存在的余额重置日期，使用简称，并在余量栏与工作桌宠气泡中显示转峰/转谷倒计时。

AI 管理中可开关“Codex 额度恢复提醒”。该开关与是否显示额度卡分开；开启时仍会读取 Codex 额度。以实际新读数确认周期重置后的增长或额度耗尽后恢复，首次读数不通知，相同恢复不重复提醒；不会只根据倒计时到期推断恢复。定期读取约每分钟一次，实际提醒时间受接口和网络影响。去重状态只保存窗口百分比和时间，不保存账号凭据。

主 Agent 回复或会话结束时，探头气泡附带该工具可读取的剩余额度。同一轮回复结束与会话结束不会重复播报；子代理完成仍保持安静。新读数尽量等待最多2秒；旧于完成事件的有效读数标为“上次剩余”，超过5分钟或读取失败时显示“额度暂不可用”。此功能不改变工具原有的额度读取能力：Grok Bot 桌面版仍无法自动读取，Gemini 桌面版仍受原生用量页面可访问性限制。

本轮已完成 Debug 和 Universal Release 编译、应用启动及安装包完整性/签名检查。界面检查工具连接超时，未完成实际目视和开关操作确认；未做真实额度重置、全部模型、多显示器、Intel 实机或大量桌宠性能验收。

数值统一采用与内网 IPv6 相同的11pt medium等宽字体，覆盖指标、速率、地址、额度、重置时间及图表坐标。软件名称、标题、操作按钮保留既有层级；超长 IPv6 仍适配整行宽度。双环只选择真实小时/周读数，不为其他周期编造比例；其他额度数据保留在该软件下方文字中。

圆环线宽4.5pt；出网与内网 IPv4/IPv6 的右边缘一致，刷新图标位于“出网 IP”名称后。地址复制、整行 IPv6、原有缓存与查询规则不变。

数值框显式固定到同一右边缘，包含 CPU/GPU/内存/储存/电池/温度与所有 IP；不再依赖内容宽度或空操作列。重新开关图表时，时长标签跟随当前排在最前的图表。

关闭仪表后的 AI 文字列表同样使用明确的右边缘约束，额度、重置时间和 DSH 峰谷倒计时各行右对齐；软件名称保留左侧列。

AI 区域使用自然内容高度，不再嵌套独立滚动区域。软件较多或文字换行时，统一由整个信息卡在超过可见页后滚动。
