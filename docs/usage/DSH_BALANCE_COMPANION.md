# DSH 主 Agent 余额桌宠

DSH 新会话开始真实工作后，主 Agent 出生在主显示器可见区域的右下角，避开 Dock；多个主 Agent 沿右下方错开。只打开空闲会话不会生成工作桌宠。主 Agent 不自动走动，仍可手动拖动、缩放和关闭。

出生介绍约2秒后，气泡持续显示余额、今日已用、当前峰价/谷价，以及还有多久转峰或转谷。AI 面板与软件选择统一简称为 DSH。

余额来自现有只读 DSH 账号余额接口；今日已用参考用户指定的 [DeepSeek-Balance-Whale-Widget](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget) v0.4.2（锁定提交5247dd6813d6e4430728f39ccc63d43cda046022），按相邻真实余额读数的下降累计消费，充值等余额增长单独记录，不抵扣消费。使用1e-8精度定点金额，按凭据身份、币种与北京时间日期隔离，不合并不同币种。

WhaleGirl 使用自己的私有观察账本，不读取或修改原挂件账本。当天首次成功读取只建立基线；当天较晚开始观察会标记“部分”，无法补出启动前或两次读取之间被充值抵消的消费。余额增长会标记“待核对”。因此这是已观测消费，不是完整官方账单，也不能保证等于已有挂件的当日累计。登录凭据变化会建立独立基线。账本损坏时保留原文件并显示不可用，不覆盖为0。

后台复用约每分钟的额度刷新，不逐帧请求网络；价格切换点补充刷新。峰谷规则参考该版本的北京时间工作日窗口9–12、14–18与2026年周末/假日表，倒计时跳过无需切换的周末和假日；未覆盖的年份不猜测排期。过期读数或未知排期显示更新中或不可用。未读取到的金额不补成0。

经典鲸鱼娘自动动作优先“工作与表情”（15个动作）和“偷吃Token”（额外播放优先级），动作之间仍回默认状态。其他皮肤缺少这些动作时使用默认状态；手动指定动作仍可使用。DSH 主 Agent 的通用思考文案由余额气泡代替，悬停不打断常驻气泡。完成后沿用告别、随机等待与光环上升退场；恢复工作取消退场并恢复气泡。子代理、手动桌宠和其他软件不变。

需要已有 DSH 真实事件接入；无需重装插件或重启 DSH。关闭 Agent 桌宠会停止常驻气泡；如果额度卡仍启用 DSH，额度读取照常。观察账本位于 WhaleGirl 用户数据目录，原子保存并限制读写权限，只保存余额变化和时间，不保存明文凭据、会话、标题或推理内容。参考项目 MIT 代码许可及署名随包保留；未复制其图片、音频或浏览器插件。

验证范围：Universal 编译、应用启动与安装包检查；4个小型用例覆盖余额下降/充值、身份与币种隔离、跨日/重复读数、损坏文件保护及周末假日切换。未启动付费模型。真实新会话完整视觉、Intel 实机、多显示器和大量桌宠性能未新增验收。
