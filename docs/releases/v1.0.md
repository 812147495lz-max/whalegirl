# whalegirl v1.0

首个公开版本。当前菜单栏互动、多桌宠、系统信息、额度适配器和 Agent 生命周期实现一并发布。

## 下载

- WhaleGirl-v1.0-Universal.dmg：拖放安装镜像。
- WhaleGirl-v1.0-Universal.zip：同一应用的压缩包。
- SHA256SUMS.txt：以上附件的 SHA-256。

最低 macOS14；含 arm64 与 x86_64。实际运行验证以 Apple silicon 为限。本地 ad-hoc 签名，未公证。

## 已知限制

Gemini 桌面版需打开用量限额页面供辅助功能读取；Grok Bot 桌面版自动额度仍未接通。额度、软件登录和工作事件是独立能力。所有软件的真实模型端到端、Intel硬件、多显示器与大量桌宠性能没有被标记为全部验收。

## 素材与隐私

发布方已确认本次完整素材公开分发许可；各素材原有署名和许可保持独立。公开源码不含个人凭据、账户数据、本机调试截图和旧开发历史。
