# WhaleGirl v1.5

本次小版本整合当前信息面板、网络诊断、额度仪表、DSH 桌宠与菜单栏调速更新。

## 更新

- 统一紧凑布局及数值字体，指标与全部 IP 右对齐，折线图可独立开关，时长只显示在首图上方。
- 网络快捷测速：常用目标/自定义网址或 IP、逐跳 IP 与延迟、下载测速、气泡结果及详情/设置。测试需手动启动，过滤或未到达的路由不会伪报为成功。
- 小型双环余量仪表每行两个软件，内圈小时/外圈周；管理页开关仪表，文字模式保持右对齐。仅真实重置时间显示倒计时。
- DSH 主 Agent 右下角固定工作，显示余额、已观测当日消费与峰谷切换；余额仪表默认满量程50元，可调整。
- Codex 真实额度恢复时提醒一次；主 Agent 完成提醒附带可读取的剩余额度，子代理继续保持安静。
- 尾巴使用连续单调计时，保留负载到帧率映射并改善变速响应，减少回调延迟积成慢放。

## 安装

下载 WhaleGirl-v1.5-Universal.dmg，拖动 WhaleGirl.app 到 Applications；也提供同一应用 ZIP 与 SHA256SUMS-v1.5.txt。最低macOS14，包含 Apple silicon/Intel。应用本地 ad-hoc 签名，未经过 Apple 公证。

## 数据与兼容边界

Gemini 桌面额度仍依赖获授权的用量页面，Grok Bot 自动额度仍未接通。登录状态、额度和工作事件是独立能力。DSH 消费从首次余额观察建立基线，可能仅覆盖当日部分时间，充值等增长另行标记，不能替代官方账单。峰谷排期参考锁定版本的北京时间规则/2026假日表，未知年份不推测。

近期8个动画计时和4个余额观察用例通过；本次仅做干净发布构建及安装包校验，不重复大范围测试或运行付费模型。实际运行以 Apple silicon 为限；Intel 实机、所有模型端到端、多显示器和大量桌宠性能未全面验收。完整第三方素材与许可保留，不变更既有独立艺术授权。
