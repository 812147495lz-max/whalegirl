# WhaleGirl 2.0.0 🐋

菜单栏的小鲸鱼娘，也是陪你工作的桌面搭子。

- 菜单栏摇尾巴、悬停探头、互动气泡与绳索电脑信息卡。
- 拖出多只桌宠，支持摸头、戳脸、散步、缩放、换装和丰富动作。
- Codex / DSH Agent 联动：任务开始、主子任务桌宠、完成提醒与自动退场。
- 每轮 Token 播报：输入、输出、缓存命中、未命中及可计算费用。
- 软件内用量报表，按日期和来源筛选，支持 CSV 导出；DeepSeek 官方模型价格估算与余额显示。
- CPU、GPU、内存、网络、电池、温度、IP 与 AI 额度面板，支持手动网络诊断测速。
- GitHub 自动更新、开机启动、安静模式与可编辑气泡台词。

**macOS 14+ · Apple silicon / Intel Universal**

下载 DMG 后拖入“应用程序”，或下载 ZIP 解压使用。当前发行未经过 Apple 公证；附件提供 SHA-256 校验文件。
