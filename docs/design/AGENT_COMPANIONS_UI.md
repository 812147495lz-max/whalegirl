# WhaleGirl · 晚间交互设计约定

2026-10-21 20:00之后开始实施。参考用户指定 ui-design 仓库固定提交 db8d1113e3d22936f5f996dcdbb365deff0e9f72 的 universal-gui/SKILL、FOUNDATIONS、STYLE_ENGINE、DATA_AND_OPERATIONS；文档为参考，不是对用户需求的替代。

- 主风格：淡蓝毛玻璃，轻微可爱点缀；原生 AppKit，窄幅236pt，维持角色锚点。避免复制网页组件或品牌。
- 层级：运行数字>指标名称>说明/时间；主字不透明，元数据至少10pt，系统字体和等宽数字。8pt间距节奏，16pt容器内边距，关键图标点击目标>=24pt。
- 状态：读取中/无数据/硬件未提供/过期有明确文案，不以0伪装缺失；高占用与低额度有辅助颜色，但数字和文案仍可独立识别。
- 材质：系统减少透明度或增强对比度时使用不透明浅蓝底；关键文字不折射、不发光。减少动态效果时，信息卡和探头气泡减少位移/过渡，保留用户指定角色素材的状态表达。
- 自定义：系统信息设置改为双列选项，紧凑但保留原生键盘焦点和清楚的全部显示/隐藏。AI选择与总开关独立。
- Agent出生：准确身份和可用任务标签，第二秒启动首次不同动作的异步加载，平时独占动作；挥手告别是明确允许共享的统一动作例外。
- 结束文案：任务标签前8字+“结束”，<=10字，标签不是成果证明；无标签/失联用诚实短句。只读取公开任务标签，不扫描回复文本。
- 验证三种代表状态：正常指标与额度、繁忙/多个子代理、无额度/传感器缺失；原生组件测试和截图，不声称浏览器审计等价于原生验收。

验证截图位于 evidence/agent-life（测试夹具数据，非当前账户或系统负载）；原生状态测试覆盖繁忙、读取中、缺失。挥手较迟时可超出随机期限等待完整播放，最多15秒保护；恢复工作取消退出。
