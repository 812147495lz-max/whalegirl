# 桌面散步调度

每只大号角色拥有独立的剩余随机动作计数。创建时及每次完整散步结束后，均匀抽取 0、1、2、3 中的一个值。自动随机动作完整播放后减一，手动点播与被打断的动作不计数。计数为零时，下次自主活动为散步；动作与散步之间保留 2–5 秒待机。连续抽到零时，允许休息后再次散步。

散步在当前显示器可用桌面范围内随机选择位置，限制单次距离，使用 3–10 秒平滑起步及停下的移动。屏幕边界按窗口大小限制。所有正在散步的角色共用一个 30 Hz 计时器，无角色走动时停止。按经过时间插值移动，避免系统繁忙时积累位置更新。

步态使用现有「原地左转奔跑」素材第 25–52 帧（零基索引 24..<52），派生 full.walk 循环，不包含转身、跌倒和恢复片段。原有完整动作与动作菜单保留。朝右时镜像步态，鼠标像素命中也对应镜像。图像及位压缩命中数据继续共享，行走不逐帧解码。

左键按下、右键菜单和菜单栏拖出期间取消散步并暂停自主调度。松手或关闭菜单后按当前动作恢复。手动点播优先，播放完成再返回自主调度。隐藏、关闭、休眠会停止移动；切出当前桌面空间会结束当前路线，不跟随进入全屏空间。

行为参考：
- https://github.com/1190fasheqi/dafeiyu-pet （MIT；随机目的地、到达后休息、移动期间暂停交互）
- https://github.com/trc667/deepseek_whalegirl_desktoppet （走路时切换步态、根据方向镜像）

这里是适配现有 Swift/AppKit 框架的实现，未复制上游 Python/JavaScript 源文件或额外引入上游美术。素材来源仍由 CommunityActions/provenance.json 与随包许可记录。

首次交付仅编译与归档。随后用户明确要求测试，已完成六项 App XCTest：0–3 次动作计数及散步后重抽、互动/手动点播/暂停打断、镜像像素命中、路线边界与拖动/隐藏停止、正式步态片段和多角色回归，全部通过。正式素材单角色能启动并显示；桌面工具右键返回 AXError.notImplemented，未完成真实右键端到端验收。多屏、全屏切换、跨应用点击穿透和长期压力仍未验收。

## 横向路线与多角色去重增量

移动按位移而非屏幕绝对坐标判断：`abs(target.x-start.x) > 1.732 * abs(target.y-start.y)`。
路线生成在合法窗口原点范围内限制纵向位移为横向位移的 1/1.733，保留严格大于的余量。
距离缩短和缓动对两个坐标使用同一个比例，不改变方向。无横向空间时不启动散步；缩放中止旧路线。

每次散步从三套步态中随机选一套：原小跑、既有「螃蟹走路」第25–88帧的横向小步走，以及
新下载的 YunYueSama 16帧侧身走路。新素材在 `walking-provenance.json` 锁定来源、提交、摘要、
帧顺序与修改说明；随包保留自定义署名许可全文。只导入图片和播放元数据，不执行上游程序。

共享 SpriteRepository 在主线程分配原地动作。所有桌面角色（包括首次出场待机、自动动作、
手动点播和交互反馈）都先预占动作；另一只占用时自动选择空闲动作。短别名按源图集视为同一个动作。
旧纹理显示期间仍保留旧动作占用，直到新纹理实际显示；取消加载后回收多余预占。隐藏时释放，
已销毁角色通过弱引用清理。不同角色可同时走路，行走不参与原地动作互斥。
动作库有限（106种），没有空闲动作时保留已有独占姿势，新角色等待可用动作，不以重复动作兜底。
本轮遵照此前不自行测试的偏好，只构建、签名和打包，不启动应用或运行 XCTest；新回归用例未执行。

## 多桌面与资源优化增量

同一显示器的不同普通Spaces复用同一组NSPanel、PetView、播放器与动作占用，不按Space复制角色。
窗口使用canJoinAllSpaces、canJoinAllApplications、stationary、ignoresCycle、fullScreenPrimary；
浮动NSPanel保持floating层级且不随应用失活隐藏。依据Apple的canJoinAllApplications文档，
fullScreenPrimary用于排除其他应用的全屏空间，不能误把fullScreenNone当作该排除开关。
工作空间切换、前台应用变化由一个共享观察器恢复现有可见窗口的顺序，不重建或重播角色。
多显示器原点仍使用全局屏幕坐标，切换Space本身不改变角色所属显示器。

107个图集去除公共透明边距，外围alpha=1/255的残留不再保留；裁切内源解码像素以无损WebP保存。
render-layout.json记录原384×216逻辑画布与裁切偏移；显示大小、位置、镜像与像素命中均按该偏移补偿。
原始累计RGBA解码体积4206919680字节，裁切后1835368960字节，减少56.4%。这是全库累计体积，
不是常驻内存、GPU显存或CPU实测值。无损重编码使磁盘包体增大；此项优化主要降低运行时解码图像面积。
可重建工具Scripts/compact_community_atlases.py在素材导入之后执行；原图集与元数据备份在工作目录。

SpriteAnimator改用一个共享30Hz时钟，按绝对帧截止时间推进，繁忙时跳过错过的绘制但限制追赶次数。
保留原动作帧时长，暂停时保存剩余时间；不可见或不在当前Space时暂停推进。
鼠标检测改为一个共享30Hz时钟，每轮只读取一次鼠标位置，指针在角色窗口外时不做像素坐标转换。
行走继续使用原共享时钟，角色数量不再增加播放/鼠标轮询Timer数量。
clip与atlas查找改为字典，待加载纹理替换前保持旧的共享位图引用；动作在解码前预占，避免撞动作后弃用解码结果。
社区LRU缓存预算从128 MiB降为64 MiB；正在显示或准备的纹理仍独立存活，因此这不是整个应用内存上限。

参考：https://developer.apple.com/documentation/appkit/nswindow/collectionbehavior-swift.struct/canjoinallapplications
本轮只构建、资源检查、签名和打包；没有启动桌宠、运行XCTest、切换用户桌面或执行压力采样。

### 移除用户指定的侧身走路

用户根据截图要求移除新下载的YunYueSama侧身走路动画。full.walk.yunyue、图集、独立manifest、
对应来源/许可和导入脚本已移出发布资源与正式工具目录，历史文件保留于work/removed-actions/yunyue-walk。
运行时不再加载walking-manifest.json，随机步态和角色点播菜单现在只剩小跑、横向小步走两种。
原始“悬挂”素材、appear/disappear/wink、菜单栏尾巴、其他社区动作均未因本次移除改变。
