# Phase 2 互动界面人工验收

本阶段用仓库现有图集预览交互流程。替换新美术后，需要重新检查每个动作帧的视觉边界和 hitbox。

## Peek / Full 控件

1. 从菜单栏打开 Peek，确认角色下方出现摸头、戳脸、拖出全身、收起四个按钮。
2. 点击摸头和戳脸按钮，确认表情/台词反馈；直接点击角色头部和脸部也能触发对应反馈。
3. 点击“拖出全身”，确认从 Peek 切换到 Full；在 Full 中点击“回到探头”，确认播放返回动作后回到 Peek。
4. Peek 和 Full 中点击收起按钮，确认角色面板关闭，菜单栏图标仍可正常点击。
5. 点击角色外的透明区域，确认底下窗口仍能接收点击；控制条按钮仍能点击。

## 拖动和显示器边界

1. 从 Peek 向下拖动角色，确认越过阈值后切换到 Full；拖动 Full 时确认角色跟随指针。
2. 在屏幕四边、菜单栏附近和 Dock 附近拖动，确认窗口保持在可见区域内。
3. 在每个显示器上分别打开 Peek/Full，并在不同缩放比例下重复检查。
4. 连续开合 200 次，确认没有额外窗口累积或明显内存增长。

## 新素材替换

1. 按 `docs/phase2/ART_ASSET_INTERFACE.md` 替换 atlas PNG 或 manifest。
2. 确认菜单栏 `MenuBarFrames/png_1`–`png_20` 与 Peek/Full 图集保持独立。
3. 运行 SpriteManifest 和资源加载测试，再逐帧检查锚点、视觉边界与 hitbox。
