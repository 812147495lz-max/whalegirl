# Phase 1 人工验收清单

所有未执行项保持“未测”。模拟 Agent 事件只能验证 UI 和协议，不能替代真实审批 Gate。

## Dashboard 与系统指标

1. 左键点击菜单栏头像，确认头顶短暂出现爱心；右键点击直接打开/收回 Peek；中键打开 Dashboard、大小和退出菜单，Option+右键仍可用作备用入口。
2. 保持 Dashboard 10 秒，确认 CPU、内存、网络和电池每秒更新且窗口无跳动。
3. 点击“打开活动监视器”，确认系统 Activity Monitor 打开。
4. 切换静音和系统通知；通知首次开启时按系统提示授权或拒绝，确认 UI 与实际结果一致。
5. 切换“登录时启动”，确认系统设置状态与 Dashboard 诊断一致；测试完成后恢复用户原设置。

## Codex 真实链路

1. 审查并安装 `Integrations/WhaleGirlCodex`，在 Codex 中确认 Hook 信任状态。
2. 启动两个独立 Codex 会话，确认 Dashboard 产生两个独立项目/会话行。
3. 让会话 A 完成一轮，确认只更新 A，文案为“完成一轮回复”。
4. 让会话 B 触发一个真实 shell 或 managed-network 授权请求，确认 B 显示“等待授权”，A 不被覆盖。
5. 批准、拒绝或中断 B，确认同会话后续事件清除等待状态。
6. 检查 `event-state.json`，确认不存在 prompt、回复正文、命令、工具输出、transcript 路径或完整工作目录。

## DSH 真实链路

1. 记录 DSH 版本和审批事件来源；只有版本锁定的 MoodBall 或审计 `approval/asked` 证据可进入确定状态。
2. 同时运行一个 DSH 会话和一个 Codex 会话，确认两者互不覆盖。
3. 无真实审批来源时，确认 Dashboard 显示“DSH 审批监控：暂不可用”，并保持 Phase 1 Gate 未通过。

## 安全与恢复

1. 检查 ipc 目录权限为 `0700`、Socket 为 `0600`。
2. 发送未知字段、无时区时间、小数秒时间、超长帧，确认诊断计数增加且 App 不崩溃。
3. 重发同一个复合事件 ID，确认不重复增加未读数；重启 App 后再发一次，确认仍去重。
4. 让 Mac 睡眠再唤醒，确认指标恢复，隐藏状态不高频采样。
5. 关闭网络后重启，确认角色、本地事件和系统指标仍可使用。
6. 静置 10 分钟后用 Activity Monitor / Instruments 记录 CPU、RSS、唤醒次数和能耗。

## 原角色互动回归

1. 右键菜单栏头像打开 Peek，测试摸头、戳脸、下拖 Full、四角边界、松手回家和 8 秒收回。
2. 在 Chrome/Finder 内容上验证角色外透明区域点击穿透。
3. 在每个显示器、菜单栏自动隐藏和刘海机型上重复 Peek / Full 定位。
